# Getting help

| You want to… | Go to |
|---|---|
| learn how to use i3 Academy (learners, trainers, organisations) | the [handbooks](https://docs.academy.i3-innovation.com/en/). Inside the platform, **Help** shows the ones for your roles |
| install or run your own server | [Run a server](https://docs.academy.i3-innovation.com/en/operate/) |
| build on the APIs, webhooks, MCP or connectors | [Develop and integrate](https://docs.academy.i3-innovation.com/en/develop/) |
| ask a question or share an idea | the repository's **Discussions** |
| report a bug you can reproduce | a new **issue** in the repository it belongs to |
| report a vulnerability | **Report a vulnerability** on the repository's **Security** tab. Please never open a public issue for one |

Issues are for bugs and concrete proposals. We cannot debug a particular installation in an issue.
Please include versions and steps, and leave out personal data.

## Hosted service and professional support

Self-hosting i3 Academy is free, now and later. If you would rather not run it yourself, or want
someone to call, there are optional services:

- the hosted service at [academy.i3-innovation.com](https://academy.i3-innovation.com);
- support contracts and managed operation for installations on your own infrastructure (see
  [pricing](https://academy.i3-innovation.com/pricing#self-hosting)).

For anything about an account on the hosted service, use **Help → Tickets** in the portal or the
[contact page](https://academy.i3-innovation.com/contact). Please do not use GitHub for it.
